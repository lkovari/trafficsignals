# Release notes — 2.0.0

**App:** Hungarian Traffic Signals (`com.lkovari.mobile.apps.trafficsignals`)  
**versionCode:** 2  
**Date:** 6 September 2026

First modern release: a Kotlin + Jetpack Compose rewrite of the 2011 Eclipse catalog ([trafficsignals-e](https://bitbucket.org/laszlokovary/trafficsignals-e/src/master/)).

## What’s new

- Nine KRESZ categories with searchable grids and a full-size sign detail screen
- English descriptions by default; Hungarian when the device locale is Hungarian
- Higher-quality sign diagrams from Wikimedia Commons Hungarian road-sign SVGs where a match exists
- First-run license screen, About with original source link, Material 3 light/dark UI
- minSdk 24, targetSdk 36
